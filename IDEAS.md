# Идеи проектов

Очередь идей для новых примеров. Автоматизация берёт первую со статусом `todo`
и реализует её. Никаких ограничений по «доступным возможностям» нет: список
ниже — стартовая точка, а не потолок. Безумные идеи приветствуются.

Если для идеи не хватает возможности Arcod (типа, эффекта, провайдера,
генератора, семантики) — это не повод отказаться: делаем столько, сколько язык
позволяет сегодня, остальное описываем в README и заводим issue в
`chubakur/arcod`. Статус `blocked` — только если проект не удалось довести до
рабочего состояния вообще; `partial` — если работает урезанно.
