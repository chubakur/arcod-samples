# Идеи проектов

Очередь идей для новых примеров. Автоматизация берёт первую со статусом `todo`,
реализует её и меняет статус на `done` со ссылкой на каталог. Статус `blocked`
означает, что проект упёрся в ограничение Arcod — ссылка на issue обязательна.

Правило ротации: каждый новый проект должен задействовать возможность Arcod,
которой ещё нет в уже готовых примерах (kv, sql, blob, queue, stream, saga,
identity, jobs, mail, llm, olap). Если все строки закрыты — добавь 3 новые идеи
в конец файла.
